# Projeto Biblioteca 📖

## 🔍 Sobre

O **Projeto Biblioteca** é uma aplicação web desenvolvida para facilitar a gestão de livros, usuários e empréstimos de uma biblioteca.

O sistema conta com uma interface responsiva, adaptada para dispositivos móveis, e funcionalidades de cadastro e autenticação de bibliotecários, permitindo o gerenciamento das operações da biblioteca de forma simples e organizada.

## 🔧 Tecnologias utilizadas

- **Linguagens:** JavaScript • TypeScript
- **Front-end:** React.js • Next.js
- **Back-end:** Node.js • Express.js
- **Banco de dados e ORM:** PostgreSQL • Prisma
- **Bibliotecas e ferramentas:** JWT • Bcrypt • React-Toastify • Zod

## 🗒️ Principais características

- **Experiência do usuário (UX/UI):** Interface desenvolvida com foco na usabilidade, facilitando a usabilidade e as operações realizadas pelo bibliotecário.
- **Responsividade:** Layout adaptado para diferentes tamanhos de tela, proporcionando uma boa experiência em dispositivos móveis.
- **Tipagem com TypeScript:** Utilização de tipagem estática para melhorar a organização do código, facilitar a manutenção e prevenir erros durante o desenvolvimento.
- **Componentização:** Interface dividida em componentes reutilizáveis, facilitando a manutenção e a escalabilidade do Front-end.
- **Validação de dados:** Utilização do Zod e React-Hook-Form para validar os dados enviados pelo bibliotecário no Front e Back end.
- **Autenticação e segurança:** Implementação de autenticação com JWT e criptografia de senhas com Bcrypt, garantindo melhor segurança dos dados.
- **Arquitetura MVC:** Back-end organizado seguindo o padrão Model-View-Controller, separando responsabilidades e facilitando a manutenção do código.
- **Gerenciamento de dados:** Integração do PostgreSQL com Prisma-ORM para gerenciar a comunicação do Back-end com o banco de dados.
