# Projeto Biblioteca 📖

## 🔍 Sobre
O presente projeto, é uma solução web pensada em facilitar a gestão de livros e empréstimos de uma biblioteca. O projeto possui uma interface responsiva para dispositivos móveis e um sistema que permite o cadastro e login dos bibliotecários.

## 🔧 Tecnologias usadas
* Javascript • TypeScript
* React.js • Next.js
* Node.js • Express.js
* PostgreSQL • Prisma
* TokenJWT • Bcrypt • React-Toastify • ZOD

## 🗒️ Características do projeto
* Utiliza princípios de UX/UI para melhorar a experiência do bibliotecário
* Desenvolvido com Tipagem forte utilizando TypeScript
* Front-end devidamente componentizado
* Utiliza a biblioteca ZOD para validação de dados
* Possui criptografia de senhas
* Backend organizado seguindo a arquitetura MVC para facilitar a manutenção
